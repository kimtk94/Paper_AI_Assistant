## 기본 코드에서 수정한 문제

1. **감사 파일 덮어쓰기:** 같은 초에 두 번 적재하면 JSONL에는 두 실행이 남지만 스냅샷·매니페스트는 하나만 남았다. UTC 시각과 UUID를 포함한 실행 ID 및 배타적 파일 생성으로 수정했다.
2. **입력 검증 우회:** Pydantic 검증 오류까지 optional-dependency fallback으로 취급했다. 잘못된 `results` 보고서가 0건 성공으로 기록되는 경우를 포함해 입력 구조·레코드 오류를 적재 전에 중단한다.
3. **가짜 PDF 성공:** HTML landing page를 `.pdf`로 저장할 수 있었다. PDF 헤더를 확인한 뒤 원자적으로 교체하며, 실패 시 기존 파일을 보존한다.
4. **PDF 재시도 누락:** DOI URL과 bare DOI·대소문자 차이 때문에 PMID 없는 논문이 재시도 목록에서 빠졌다. 같은 정규화 키로 대조한다.
5. **연도 오분류:** `PMC2012345.pdf`에서 2012를 발행연도로 읽었다. 식별자 내부 숫자를 제외하고 독립된 연도 토큰을 사용한다.
6. **PubMed 오류의 성공 처리:** HTTP 200의 오류 JSON/XML, 누락·중복 응답, 파싱 가능한 오류 캐시를 정상 0건 결과로 처리할 수 있었다. 응답 구조·건수·논문 ID를 검증하고 불완전한 검색 구간을 완료 처리하지 않는다. version 1 체크포인트는 재검색한다.
7. **CI 범위:** 테스트 대상이 SKKU 코드에만 한정돼 있었다. 기본 코드 전체의 결정적 테스트를 실행하고 외부 PubMed 통합 검증은 수동 선택으로 분리했다.

검증 명령: `python -m unittest discover -s tests -p 'test_*.py' -v` 및 `python -m compileall -q src tests`. PDF 검증은 시그니처 확인이며 완전한 PDF 파서 검증은 아니다. JSONL 적재는 동일 번들의 중복 실행을 제거하거나 모든 출력 파일을 단일 트랜잭션으로 저장하지 않는다.
